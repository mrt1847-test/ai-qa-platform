# Android 자연어 자동화 데모

[전체 영상](android-no-code-demo.mp4) · [움직이는 미리보기](android-no-code-demo.gif) · [실행 근거](android-no-code-demo-evidence.json)

2026-11-17에 실제 제품 웹 UI와 Android 에뮬레이터에서 새로 촬영했다. 웹에서 기기·대상 앱 선택 → 자연어 입력 → 초안 저장 → AI 녹화 시작 → 저장된 화면·로그 확인 → 저장본 시범 접수 → 재생 증거와 결과 확인 순서다. 영상은 해당 실행의 새 브라우저 촬영 구간을 편집했으며 대기를 줄이고 자막을 추가했다.

## 확인한 실행

| 항목 | 관찰 |
| --- | --- |
| 설치 파일 | 사용자가 지정한 `C:\apk\GmarketMobile-prod-debugFinal-20260429_032548.apk` |
| 앱 | `com.ebay.kr.gmarket` · `10.8.6-debugFinal` |
| 기기 | `Medium_Phone_API_36` · `emulator-5580` · 1080×2400 |
| 목표 | G마켓 검색 화면을 열고 검색어 입력란 확인 |
| 녹화 | 실제 고정 Mobile-Agent 원본 경로 · 모델 요청 2회 · 탭 1회 |
| 저장 | 녹화 완료 · 전후 화면·로그 서버 보관 · 재생 패키지 생성 |
| 시범 | 저장 패키지 사용 · 실제 탭 1회 관찰 · 모델 요청 0회 · healing OFF |
| QA 결과 | `INCONCLUSIVE` · 최종 검증 대상 평가 연결 개발 중 |
| 사람 승인 | 미수행 |

탭 좌표는 `(339, 2272)`다. 녹화 후 앱 데이터와 화면을 초기화하지 않았으며, 시범은 검색 화면에서 저장된 탭을 재생했다. 재생 명령의 실제 전달·관찰과 기대값에 대한 QA 판정은 구분한다.

프로젝트·모델 연결·실행 PC는 별도의 임시 데모 환경에 준비했다. 웹 UI의 녹화 시작과 시범 접수는 정상 API를 사용했고, 워커는 실제 HTTPS·ADB 경로를 사용했다. APK 설치 직후의 안내 처리와 에뮬레이터 복구는 촬영 전 준비에 해당한다. 에이전트의 녹화 동작이나 시범 재생으로 계산하지 않았다.

## 영상 범위

- 영상과 미리보기에는 완료한 검색 화면 열기 녹화와 그 저장본의 시범만 포함한다. 이전 `AI-LIVE-03`의 캡처는 사용하지 않았다.
- 브라우저 UI의 실제 입력·클릭·페이지 전환을 새로 캡처했다. 화면 갱신에는 실제 새로고침이 포함된다.
- 07·12번 증거 확인 구간은 뷰어의 화면 잘림을 수정한 뒤 같은 실행의 저장된 증거를 다시 촬영했다. 이 구간 교체를 위해 모델 호출이나 기기 재생을 추가로 수행하지 않았다.
- 별도로 시도한 검색·홈 복귀 촬영은 이 영상에 포함하지 않는다.
- 최종 검증 PASS, 사람의 사후 승인, 승인본 정식 회귀 완료를 시연한 것으로 해석하지 않는다.
- APK, API 키, 런타임 DB, 브라우저 세션은 영상 파일에 포함하거나 저장소에 추가하지 않았다. 앱 화면에는 공개 상품·광고가 표시될 수 있다.

실행 ID, 모델 요청 수, 저장 패키지·영상 해시와 편집 구간은 [실행 근거 JSON](android-no-code-demo-evidence.json)에 보존한다. 관련 구현 진행은 [NEXT_ACTION](../../NEXT_ACTION.md)과 [검토·재생 여정 작업서](../managed-pc/MOBILE_AGENT_REVIEW_JOURNEY_TASKS.md)를 따른다.
