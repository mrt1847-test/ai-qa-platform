# 증거 뷰어 전체보기 화면 잘림 수정

2026-11-17. README Android 영상에서 전체보기가 원본 배율로 바뀌면서 1080×2400 캡처가 잘리고, 고정 높이 300px 영역에 스크롤바가 생기는 문제를 수정했다.

- 전체보기와 이미지 배율을 분리했다. 맞추기·100%·확대·이동의 선택은 전체보기 진입·종료에도 유지한다.
- 명령 요약을 압축하고, 참조·로그를 이미지 아래로 배치했다. 이미지 쌍은 화면의 남은 높이를 사용한다.
- 브라우저 전체화면이 제한되면 페이지 안에서 전체보기를 제공한다. 닫기 또는 Esc로 복귀한다.
- 기존 실행의 저장된 실제 증거로 영상 07·12 구간을 다시 촬영했다. 실행 ID와 모델 호출 수는 유지했다.

## 확인 결과

| 실제 브라우저 크기 | 맞춤 이미지 | 이미지 영역 | 가로/세로 스크롤 초과 |
| --- | --- | --- | --- |
| 1280×720 | 각 210.24×467.19px | 각 454×468.80px | 0 / 0px |
| 360×800 | 각 158.21×351.58px | 각 162×353.20px | 0 / 0px |

1080×2400 원본의 전체 비율을 보존했다. 100% 선택 시 폭 1080px로 확대되고, 맞추기로 복귀하면 다시 영역 안에 들어온다. 페이지 안 전체보기의 Esc 종료도 확인했다.

검증 명령:

```text
node --test tests/web/evidence_viewer.test.cjs
.venv\Scripts\python.exe -m pytest tests/acceptance/test_w18.py -q
```

회귀 테스트는 Promise 반환 여부에 따른 전체보기 종료, 맞춤/확대 배율 유지, 브라우저 전체화면 제한 시 대체 표시와 종료를 확인한다. 증거 선택·보관·검토 관련 acceptance 테스트 5개를 통과했다.

영상 및 미리보기의 실행 출처와 파일 해시는 [촬영 근거](../../media/android-no-code-demo-evidence.json)에 기록했다.
