# 분석 시점과 장기 사실

보고 시점은 프로젝트 commit seq다. 접수 seq가 시점 이전인 항목만 분모에 있고, 확정 seq가 시점 이전인 항목만 확정이다. 측정 비용은 같은 시점 이전의 원장만 더한다. 더 늦은 보정은 그 시점의 내보내기에 들어가지 않는다.

상세 본문은 90일, 화면은 30일이 지나면 비울 수 있다. 분모, 진행, 확정, 내용 해시, 지문 키, 비용은 장기 사실·생애·원장으로 다시 만든다. 캐시는 그 결과를 담는 projection이며, 지우면 같은 산식 버전으로 다시 만든다. 산식 버전이 다르면 다른 보고다.
