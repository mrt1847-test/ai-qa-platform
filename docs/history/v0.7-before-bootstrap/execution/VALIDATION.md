## 의미·누락 검토

단순 ID 검사를 넘어 기존 DESIGN/DATA/UI/실행 spec과 대조해32개 보완을 반영했다.
대표적으로 case 설정 편집, 기기 preview 소속, diff/수락 영속성, 메모 순번,
compiler 통합 순서, 실제 FK 부모 schema, 동작 재시도/ACK 보관, 전체 PC 백업 권한과 API/worker 역할을 보완했다.
내용·담당·남은 실제 gate는 [REVIEW](REVIEW.md)에 기록했다.

## 이번에 실행하지 않은 것

제품 코드 작성·설치·VM/USB/실제 모델 호출·제품 DB migration/부하·실제 UI/회귀·배포는 수행하지 않았다.
따라서 이 기록은 제품 기능/성공률/격리/DB 안전성의 실제 합격 근거가 아니다.
그 근거는 각 작업 구현 때 `docs/validation/tasks/{ID}.md`에 남기고, W27/W28/W32에서 통합 확인한다.

## 후속 변경 때 다시 대조할 항목

TASK_INDEX와 카드의 ID/상태/선행/경로/계약/검사 기대를 함께 바꾸고,
UI_COVERAGE/COVERAGE/root 진행률·계약 소비자를 대조한다.
부모 W 완료를 leaf 완료로 추정하거나 담당 배정만으로 실제 PASS를 만들지 않는다.
