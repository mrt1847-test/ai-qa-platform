- worker/recording_limits.py resolve_recording_limits(snapshot, worker_actions, worker_seconds)는 RX97 pin을 검증해 detached immutable RecordingLimits를 만든다. worker/전역 action·timeout과 pin model-call cap의 최솟값만 사용한다. invalid/bool/NaN/infinity/손상 pin은 거절한다. pin 없는 개발 fixture의 기존 semantics는 보존한다.
- AndroidRecordingHandler는 claim마다 새 action/model/time 한도를 소비한다. shared context를 수정하지 않고 통계·계획 cursor·시계를 재설정한다. 새로운 pin의 주입 monotonic clock도 claim-relative이며 실제 monotonic clock을 사용하면 모델 대기/PNG·journal I/O가 elapsed에 포함된다.
- RemoteLeaseGuard.begin_attempt는 새 attempt의 내부 action/model counter를 초기화한다. 예비 gate는 noncharging before_lookup, 모델 gate는 before_model, native-send 경계의 최종 gate만 before_dispatch를 한번 차감한다. 같은 attempt 재호출의 counter는 유지한다. RX98 서버 영속 모델 quota를 대체하지 않는다.
- AndroidDeterministicDriver.run의 optional before_native_send callback은 preflight·argv/정제 spool 뒤 실제 _runner 직전에 호출된다. MobileAgentAndroidAdapter가 신뢰 worker callback을 전달한다. 모델 payload에서 callback을 생성하지 않는다. handler는 durable dispatch_started 직후 취소·시간·guard를 다시 확인하고 그 뒤 native를 호출한다.
- journal write 이후 실제 native를 호출하지 않았음이 확인되면 local terminal not_sent를 fsync한다. wire evidence DISPATCH_STATES/DB CHECK는 확장하지 않았다. not_sent는 자동 동일-action 재실행을 허용하지 않는다. 기록 실패로 전송 여부를 안전하게 재구성할 수 없으면 기존 ambiguous/quarantine 쪽으로 남긴다.
