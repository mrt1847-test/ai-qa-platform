## 제공 interface

`AndroidObservationProvider(adb_path: Path, serial: str, *, expected_avd: str | None, command_timeout=10, observation_timeout=30).observe(capture=True) -> AndroidObservationResult`.

- 절대 ADB 경로·명시 serial·에뮬레이터의 expected AVD를 검사한다. import/생성 시 ADB 초기화0. 모든 명령은 지정 `-s`와 고정 인자 배열·deadline을 사용한다. 발견 목록으로 다른 기기를 고르거나 실패 명령을 재시도하지 않는다.
- 상태는 ready/offline/unauthorized/booting/unavailable/capture_unavailable이며 reason은 고정 코드다. 프로세스 원 stderr/예외·raw dump는 결과에 넣지 않는다.
- 결과에 serial/device_kind/AVD/Android/API/model/density/geometry/UTC observed_at을 제공한다. `capture=False`는 metadata-only로 PNG 없이 반환한다. InventoryReport의4상태에 대한 의미 있는 매핑은 AD-02 담당이며 관찰 ready를 실행 접수 허가로 쓰지 않는다.
- capture의 유효 PNG·현재 디스플레이·rotation/override를 검증하고 capture 뒤 serial/AVD/geometry를 재검사한다. 불명 회전·기본 viewport의 모순·캡처 중 변화를 추정으로 보완하지 않는다. 기본 화면 전체 bounds이며 앱 content bounds가 아니다.
- stdout8MB/stderr64KiB 상한은 읽는 중 적용하고 초과/timeout 시 이 호출이 만든 child만 종료·회수한다. 캡처는 기존 PNG CRC/픽셀 검사와 RGB/RGBA8+sRGB/sBIT의 명시 screenshot subset만 허용한다. 지원 안 되는 형식은 capture_invalid다.
- `observation`은 기존 typed Observation이고 raw PNG는 메모리에만 있다. `sanitized=False`이며 민감 픽셀 정제·FLAG_SECURE 대응을 증명하지 않는다. 이 결과를 바로 spool/model/upload에 넘기면 안 된다. 유효하지 않은 capture에는 Observation을 반환하지 않는다.

## 인계

AD-02는 위 provider의 관찰을 인증된 기존 inventory에 연결한다. 이 단계는 API route나 기기 목록을 추가하지 않았으므로 웹에서 아직 새 에뮬레이터가 자동 선택되지는 않는다. 원래 W126/163·USB/양 플랫폼·모델/격리 수용 상태는 보존한다. 동일 serial/AVD의 재시작 세대 식별과 lease는 후속 session/worker 통합에서 소비하며 이 관찰만으로 dispatch를 허가하지 않는다.
