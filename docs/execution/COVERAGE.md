## 4. 실제 기능 근거가 필요한 종료 gate

- P0 탐색: W01–03의 원본 위치/lock/VM/USB/capture/직접 replay 실제 근거. 불가면 설계를 재검토하고 후속 구현을 막는다.
- DB: W04–06의 migration/소속/불변 제약, W19의 원자 승인, W26의 GC/복원, W27의 장애/부하를 각각 검사한다.
- 녹화/승인: TC0·동작별 전후·실패/중단 선저장·사후 exact 검토, 재녹화 중 old default 보존이다.
- 실행: actor0/명시 verifier/기본OFF/한도 내 ON·미dispatch/동일 target·불명 재dispatch0·제품FAIL 유지다.
- UI: 위 요구와94개 조작의 실제 연결 + UI21개 동선 + 두 플랫폼 회귀 근거다.
- 비용: 월3000TC/최소30RUN 가정·대표 표본/사람 oracle·usage 누락/실제 tariff/조건·오판/저장량을 함께 기록한다.
- 아직 고정할 수 없는 실제 엔진/driver/모델/네트워크/OS 가용성은 REVIEW의 미래 gate로 남긴다. 구현 검증 없이 보장하지 않는다.

## 5. 기반·native 수용의 분리

W00-01–04는 최소 import/app/page/HTTP process 실행만 검증한다. 실제 DB/queue/core API/UI는 native adapter와 분리해 구현할 수 있다.
parent_gate_tasks가 남은 부모/MVP는 core leaf가 완료되어도 미완료다. W31-07·W16-04/07·W17-04·W19-04·W22-04·W27/W28/W32의 실제 조건을 지우지 않는다.
