[MP4 영상](android-no-code-demo.mp4) · [GIF 미리보기](android-no-code-demo.gif) · [실행 근거 JSON](android-no-code-demo-evidence.json)

2026-11-19(KST)에 QA Studio 전용 브라우저 창을 Windows Graphics Capture로 **연속 녹화**했다. 웹의 실제 Android 실시간 영상에서 탭 전환과 상품 로딩이 보인다. MP4와 GIF는 이 동영상만 잘라 편집했으며, 캡처 이미지를 이어 붙였던 기존 파일을 교체했다.

## 촬영 흐름

1. 웹에서 Android 기기와 G마켓 앱을 선택한다.
2. 자연어, 사전조건, Assertion을 저장하고 AI 녹화를 시작한다.
3. Mobile-Agent가 베스트 탭을 열고 상품 이미지·가격을 확인한 뒤 종료한다.
4. 서버에 저장된 후보를 열고 같은 패키지로 시범을 접수한다.
5. 저장된 탭을 실제 기기에 재생하고 결과·전후 화면을 확인한다.

Mobile-Agent의 화면 확인 후 성공 종료와, 시범의 독립적인 최종 Assertion 판정은 별개다. 후자의 평가 대상 연결은 개발 중이므로 이 영상을 QA PASS 시연으로 소개하지 않는다.

## 편집·범위

- 약 96초 MP4와 약 38초 GIF. 대기 구간을 자르고 구간별로 1~4배속을 적용했다. 정확한 원본 구간·배속은 실행 근거 JSON에 남겼다.
- 브라우저 주소·안내 막대를 잘랐다. 음성, 다른 앱 창, 이미지 합성 장면은 포함하지 않았다. 포스터만 동영상의 한 프레임이다.
- 웹 타임라인 갱신 요청이 거절돼 진행·완료 확인에 실제 새로고침을 사용했다. 촬영 전 앱을 홈으로 다시 여는 준비 작업은 저장 동작으로 계산하지 않았다.
- 먼저 시도한 스크롤 녹화는 전달 전 중단됐다. 해당 실행 장면과 예전 데모의 이미지는 사용하지 않았다. 촬영에 사용한 완료 녹화와 시범의 ID는 JSON에 분리해 기록했다.
- 영상 파일은 README용 촬영 산출물이다. 제품의 실시간 보기에는 영상 저장·다운로드 기능을 추가하지 않았다.
- API 키, APK, 런타임 DB와 브라우저 세션은 저장소에 추가하지 않았다. 앱에는 공개 상품·광고가 표시된다.
