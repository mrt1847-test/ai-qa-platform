Interface: run_mobile_agent_process(output:Path,instruction:str,capture:Callable[[],Observation],model:Callable[...,str],dispatch:Callable[...,AndroidDispatchResult],secrets:tuple[str,...],allowed:Callable[[],bool],max_steps:int=10,max_actions:int=50,timeout_seconds:float=240) -> immutable ProcessResult(status,reason,model_requests,native_actions,ambiguous_dispatch,receipt). model receives original messages with images replaced by parent-captured authoritative MobileAgentModelFrame bindings (validated PNG/geometry/observation_id/captured_at/platform only), plus before_send callback. dispatch receives exact typed action/last capture and before_send; callback must call the boundary once immediately before the bounded port sends. model_requests means parent delegation, not actual provider billing. Receipt must identify actual main invocation and pinned commit, not merely a parser.

Global constraints: new output directory only/no delete or reuse; child Python executable and module fixed; minimal OS/Python env allowlist excludes API keys/worker tokens/proxies; child Python socket connection disabled (not an OS security sandbox). Required secrets tuple uses filter_capture; unprovable sensitive pixels fail before child/model write. Parent never executes child code or receives arbitrary shell. Each capture path is bound to the parent image, at most81 frames. Messages<=4MiB, images<=2MB valid PNG, fixed seq increment, one outstanding operation. Model/native caps and monotonic cutoff checked at each before_send; in-flight callback I/O drains under existing bounded port timeout. Never retry a callback or native send. Failure after native boundary is ambiguous; already ACKed prefix retained in result. Parent kills/reaps only its own child and drains bounded stderr. Source-checkout+optional Pillow is the current supported worker packaging; wheel vendor inclusion is not claimed.
