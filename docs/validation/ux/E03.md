# E03 — 사람이 읽는 검증 편집

2026-11-01 · 상태: **core/UI 검증** · 실행 분기 `codex/ui-ux-improvements`, 기준 snapshot `232ea88`.

자연어/조건/변수/비밀 참조/경로를 편집한다. JSON은 고급 읽기 전용이며 미편집 설정·복합 값·null을 보존한다. 충돌은 비교 후 명시 새 기준으로 준비한다.
