- 상태: complete (core_contract). 부모 revision 62035c0. 이 파일을 포함한 커밋이 완료 revision이다.
- 적용 계약: C00/C01/C09/C14, UI-09. DB migration 없음.
- 소비한 선행: RX-89의 정식 준비와 preview 차단 표시.

## 제공 interface

시범, 선택 정식, 묶음 정식, 재실행 준비는 `1 대상 → 2 환경·데이터 → 3 사전 점검 → 4 최종 확인`을 같은 순서로 연다. 최종 확인은 preview가 `ready`인 뒤에만 열리고, 접수 버튼은 그 화면에 있다.

preview 응답의 `confirmation`은 서버가 고정한 버전, 승인, 환경, 기기, 데이터, 배포, 실패 정책, 초기화, 검증 방식, 행동 상한, 검증 호출 상한, 시간, 예산, 행동 AI 호출 상한 0, 복구 상한을 담는다. 화면은 이 값을 예상 상한으로 보여 주고 실제 비용이라고 쓰지 않는다. 재실행은 저장된 구성을 다시 쓰며 범위와 사유만 새로 확정한다.

이전, 취소, 수정, 방향키로 단계를 이동한다. 입력이 바뀌면 최종 확인을 닫고 다시 검사한다. 접수 응답 409·422·403과 응답 유실은 기존 재시도를 유지한다. 시범 복구 토글은 비활성이다.
